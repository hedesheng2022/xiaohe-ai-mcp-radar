# Codex 只读验证示例

不要根据榜单直接安装未知项目。先把目标项目的上游链接交给 Codex，让它核对当前 README、运行时、权限和许可证：

```text
请只读取这个 MCP 项目的官方仓库和当前 README，说明安装前置条件、需要的权限、会访问的数据、是否包含写入或删除能力，以及适合我当前系统的配置方式。先不要安装。等我确认后，只在测试目录或测试账号中安装，并先执行无副作用的读取任务。
```

安装后先运行 `codex mcp list` 确认登记状态，再用公开或测试对象做第一次读取。不要把完整 Token、Cookie 或生产数据库连接串写进聊天、截图或 Git 仓库。
