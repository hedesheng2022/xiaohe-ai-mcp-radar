## 数据怎么用

`data/mcp-directory.json` 适合程序读取，`data/mcp-directory.csv` 适合表格分析。每条记录都保留上游来源和小贺 AI 中文详情页，不复制第三方 README、源码或图片。

`verification_level` 只描述本站完成到哪一步：

- `metadata_only`：自动读取公开元数据，未安装、未调用。
- `editorial_metadata_review`：人工整理过用途与边界，但不代表安装成功。
- `sandbox_install_tested` / `tool_call_tested`：只有存在对应证据时才会出现。

## 更新节奏

日常运行会采集候选、计算热度、按阈值准入并生成网站页面。每月复盘时可以按当前热度替换低价值条目。具体变化见 [CHANGELOG.md](CHANGELOG.md)。
